## ✨ Highlights & Features

This portfolio is built with a focus on **aesthetics**, **performance**, and **user experience**.

- 🎨 **Modern Glassmorphism UI**: A stunning dark theme adorned with vibrant gradients, glowing orbs, and seamless hover effects.
- 🚀 **Interactive Animations**: Dynamic hero section with floating particles, typed text effects, and tilt animations on project cards.
- 📱 **Fully Responsive**: Flawlessly adapts to all devices, from ultra-wide monitors to the smallest mobile screens.
- 📜 **Lightbox Gallery**: A custom, swipe-friendly modal to beautifully display certifications.
- 🛡️ **Built-In Security**: Includes strict privacy scripts disabling right-clicks, developer tools, and keyboard screenshot shortcuts to protect content.

## 🔒 Security & Privacy Features

This repository includes custom client-side security measures to prevent unauthorized copying of content:
- 🚫 **Context Menu Blocked:** Disables right-clicking anywhere on the site.
- 🚫 **DevTools Blocked:** Intercepts `F12`, `Ctrl+Shift+I`, and `Ctrl+U` to restrict viewing the source code.
- 🚫 **Screenshot Mitigation:** Listens for `PrintScreen` or `Win+Shift+S` and actively attempts to clear the clipboard.
- 🚫 **Image Dragging Blocked:** Prevents users from dragging images to save them.
